
# Техническое задание

## Название
FileAge Tracker

## Цель
Создать расширение VS Code для просмотра
и анализа истории изменений Git-проекта.

## Функциональные требования

1. Получать последние 20 коммитов проекта.
2. Показывать автора каждого коммита.
3. Показывать дату и описание коммита.
4. Показывать изменённые файлы.
5. Подсчитывать количество коммитов каждого автора.
6. Выводить результаты в VS Code.

## Требования к работе

- Плагин должен работать в Visual Studio Code.
- Язык разработки — TypeScript.
- Для истории используется локальный Git.
- При отсутствии открытого проекта
  должно выводиться сообщение об ошибке.
