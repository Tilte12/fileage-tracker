## 2. Описание проекта

FileAge Tracker — расширение для Visual Studio Code, предназначенное для просмотра истории изменений проекта с использованием системы контроля версий Git.

Плагин позволяет узнать, кто и когда изменял проект, какие коммиты были созданы и какие файлы были затронуты.

Основная цель расширения — упростить получение информации об истории проекта без необходимости самостоятельно вводить команды Git в терминале.

## 3. Возможности плагина

FileAge Tracker позволяет:

- Просматривать последние 20 коммитов проекта.
- Получать сокращённый идентификатор каждого коммита.
- Узнавать имя автора коммита.
- Просматривать дату создания коммита.
- Читать описание выполненных изменений.
- Получать список файлов, изменённых в каждом коммите.
- Выводить всю информацию в отдельную панель Output в VS Code.

## 4. Используемые технологии

При разработке использовались:

## 5. Архитектура плагина

Основной код расширения находится в файле `src/extension.ts`.

При запуске команды плагин выполняет следующие действия:

1. Получает путь к открытой папке проекта.
2. Проверяет, открыта ли папка в VS Code.
3. Формирует массив аргументов для команды Git.
4. Запускает `git log` с помощью функции `execFile()`.
5. Получает информацию о коммитах.
6. Создаёт панель Output.
7. Выводит полученную историю изменений проекта.

Если папка не открыта или Git не может получить историю, пользователю выводится сообщение об ошибке.

### Основные элементы программы

**`activate()`** — функция активации расширения, в которой регистрируется команда.

**`vscode.workspace.workspaceFolders`** — получение информации об открытой папке проекта.

**`execFile()`** — функция запуска внешней программы Git.

**`args`** — массив аргументов команды Git.

**`vscode.window.createOutputChannel()`** — создание панели для отображения результатов.

## 6. Установка и запуск

Для запуска необходимы:

- Visual Studio Code.
- Node.js и npm.
- Git.

Порядок запуска:

1. Открыть папку FileAge Tracker в VS Code.
2. Открыть терминал.
3. Установить зависимости командой:

   `npm install`

4. Скомпилировать проект:

   `npm run compile`

5. Нажать `F5` для запуска расширения.
6. В новом окне VS Code открыть проект, содержащий Git-репозиторий.

## 7. Использование

1. Открыть проект с историей Git.
2. Нажать `Ctrl + Shift + P`.
3. Найти команду `FileAge: Show Project History`.
4. Запустить её.
5. Просмотреть результат в панели Output.

Пример вывода:


## 8. Преимущества и ограничения

### Преимущества

- Простой способ просмотра Git-истории.
- Не требуется вводить команды Git вручную.
- Информация об авторах, датах и изменённых файлах отображается в одном месте.
- Работа с локальным Git-репозиторием без подключения к интернету.
- Возможность использования при командной разработке.

### Ограничения

- Для работы необходим установленный Git.
- Проект должен содержать Git-репозиторий с коммитами.
- Отображаются только последние 20 коммитов.
- Незакоммиченные изменения не отображаются.
- Плагин показывает названия изменённых файлов, но не содержимое изменений.
- В текущей версии используется первая открытая папка рабочего пространства.
