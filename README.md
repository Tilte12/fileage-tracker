## Описание проекта

FileAge Tracker — расширение для Visual Studio Code, предназначенное для просмотра и анализа истории изменений проекта с помощью Git.

Плагин позволяет получать информацию о последних коммитах проекта: их авторах, датах, описаниях и изменённых файлах.

Также расширение подсчитывает количество коммитов каждого автора, что позволяет оценить активность участников разработки.

Основная цель плагина — упростить просмотр истории изменений без необходимости вручную вводить команды Git в терминале.

## Возможности плагина

- Просмотр последних 20 коммитов проекта.
- Отображение сокращённого хеша каждого коммита.
- Получение имени автора коммита.
- Отображение даты создания коммита.
- Просмотр описания коммита.
- Просмотр списка файлов, изменённых в каждом коммите.
- Подсчёт количества коммитов каждого автора.
- Вывод информации в панель Output в Visual Studio Code.
- Обработка ошибок при отсутствии открытого проекта или невозможности получить историю Git.

## Принцип работы

После запуска команды `FileAge: Show Project History` плагин выполняет следующие действия:

1. Получает путь к открытой папке проекта.
2. Формирует массив аргументов для команды `git log`.
3. Запускает Git с помощью функции `execFile()`.
4. Получает историю последних 20 коммитов.
5. Выводит информацию об изменениях в панель Output.
6. Разбивает полученный текст на строки.
7. Находит имена авторов коммитов.
8. Подсчитывает количество коммитов каждого автора с помощью структуры данных `Map`.
9. Выводит статистику активности авторов.

Подробное описание алгоритма и используемых функций приведено в `DOCUMENTATION.md`.

## Установка и запуск

Для работы необходимы:

- Visual Studio Code.
- Node.js и npm.
- Git.

Порядок запуска:

1. Скачать или клонировать репозиторий.
2. Открыть папку `fileage-tracker` в Visual Studio Code.
3. Открыть терминал.
4. Установить зависимости:

   ```bash
   npm install
   ```

5. Скомпилировать проект:

   ```bash
   npm run compile
   ```

6. Нажать `F5` для запуска расширения.
7. В новом окне VS Code открыть папку с Git-репозиторием.

## Использование

1. Нажать `Ctrl + Shift + P`.
2. Ввести `FileAge: Show Project History`.
3. Выбрать найденную команду.
4. Просмотреть результат в панели Output.

## Ограничения

- Для работы требуется установленный Git.
- Проект должен содержать историю коммитов.
- Плагин обрабатывает только последние 20 коммитов.
- Незакоммиченные изменения не учитываются.
- Статистика подсчитывается по именам авторов.
- Плагин показывает список изменённых файлов, но не сами изменения строк.
- В текущей версии используется первая открытая папка проекта.
